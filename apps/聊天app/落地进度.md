| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/moments` | 朋友圈列表 |
| POST | `/api/v1/moments` | 发动态（`text` / `images[]` / `scope`） |
| DELETE | `/api/v1/moments/:id` | 删自己的动态 |
| PATCH | `/api/v1/moments/:id` | 改 `scope`（公开 / 仅自己 / 部分可见）与 `visibleTo[]` |
| POST | `/api/v1/moments/:id/like` | 切换赞（你） |
| POST | `/api/v1/moments/:id/comments` | 评论 |
| GET/POST | `/api/v1/chat/favorites` | 收藏列表 / 新增 |
| DELETE | `/api/v1/chat/favorites/:id` | 删收藏 |
| GET/POST | `/api/v1/chat/messages` | 列表；POST **强制** SSE |
| DELETE | `/api/v1/chat/messages` | 清空本会话消息（偏好/额度保留） |
| POST | `/api/v1/chat/messages/:id/regenerate` | 同气泡重生（SSE） |
| POST | `/api/v1/chat/messages/:id/variant` | 切换 `variants` 版本 |
| DELETE | `/api/v1/chat/messages/:id` | 删一条消息 |
| POST | `/api/v1/chat/messages/:id/react` | 切换表情回应（`emoji`） |
| POST | `/api/v1/chat/messages/:id/transcribe` | 语音转文字：首次真识别 / stub；再点折叠收起 |
| POST | `/api/v1/chat/pat` | 拍一拍（`target: bot\|you`） |
| GET | `/api/v1/chat/search` | 记录检索 |
| GET | `/api/v1/chat/tools` | 内置 +（若开）MCP 工具一览 |
| POST | `/api/v1/chat/mcp/ping` | MCP 测连通（表单 URL/Token，绕缓存） |
| GET/PATCH | `/api/v1/chat/prefs` | 聊天偏好（含 `slow_reply`） |
| GET | `/api/v1/chat/mood` | 心情快照（pa/na/label） |
| POST | `/api/v1/chat/translate` | 短讯/动态文案翻译（不落库） |
| POST | `/api/v1/chat/call/start` | 模拟来电邀请（`media: voice\|video`） |
| POST | `/api/v1/chat/call/:id/phase` | 更新通话阶段 |
| POST | `/api/v1/chat/call/:id/finish` | 拒绝/结束（ended 时 SSE 接话） |
| GET/POST | `/api/v1/chat/stickers` | 贴纸 |
| POST | `/api/v1/chat/media` | 图片 |
| GET/POST | `/api/v1/chat/unread` · `/read` · `/poke` | 未读 / 已读 / 主动短讯 |
| POST | `/api/v1/chat/money/claim` | 领红包/转账（可附 `tip_message` / `receipt_message`） |
| GET | `/api/v1/wallet` | 零花余额（资产模块；发钱 sheet 用） |
