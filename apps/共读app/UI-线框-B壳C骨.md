# 共读小屋 UI · 四屏线框（B 壳 + C 骨）

> 先壳后皮。灰盒可点即可；图标与多主题后贴。  
> 对应功能清单「界面与窗格」。  
> **导航定案（线框原文）**：好看在壳与待机；**枢纽 = 底部 Tab + 复古卡片页**；共读中藏导航。侧轨 / 客厅家具场景 = 日后主题备选，默认不做。  
> **现行实现（2026-10-10 覆盖）**：锁屏 → 桌面（组件行/双头像/胶囊/栅格/Dock）→ 共读小屋 / 设置 / 日历 / 聊天 / 共看 / 共听等 → 共读中；详见 [`落地进度.md`](./落地进度.md) 与 [`UI-Design.md`](./UI-Design.md) §1。本线框下列「三态 / 待机继续 / 空 Dock」作历史灰盒备查，**不以之为真源**。  
> **实现勾选**：共读 → 本目录落地进度；小手机其它 App → 母仓 [`../../小手机-落地进度.md`](../../小手机-落地进度.md)。

## 总结构

```
┌─────────────────────┐
│     小手机外框       │
│  ┌───────────────┐  │
│  │   屏内内容     │  │
│  │  (导航切换)    │  │
│  └───────────────┘  │
└─────────────────────┘

现行导航：
  锁屏 → 上滑 → 桌面 →「共读」→ 小屋枢纽（底栏 Tab）
                      →「设置」→ 手机设置
                      → 日历/聊天/共看/共听 → 各真路径
  小屋点书 → 共读中 → 结束 → 回书架 Tab（不回锁屏）

（以下为线框原稿三态，已过时，仅备查）
  待机（极简）
    → 上滑 → 小屋枢纽（底栏 Tab：书架 / 笔记 / 记录 / 设定）
    → 继续 / Chatbox 开场 → 共读中
    → 结束本场 → 摘要卡 → **回小屋枢纽·书架**（不回待机）
```

```
好看在「壳与待机」；枢纽在「底栏 Tab + 卡片」；共读时让路给跟批。
待机不堆功能；书架/笔记/记录/设定 = 四个 Tab，复古卡片列表/网格，不再用家具场景当入口。
```

不做「屏 0 进门锁页」（房间钥匙可选，非必要，默认不加）。

分屏共读中：内容**铺满 PWA 窗格**；外框可减到细边，避免大屏半幅中间「小手机留白」。

## 屏 1 · 待机（B）

**目的**：打开就「在」。无底栏。**只保留：问候 + 一个主动作 + 上滑进小屋。**

```
┌──────────────────┐
│ ░░ 顶区氛围 ░░   │  ← 窗光打底 + 呼吸为主（见下）；非假听筒装饰
├──────────────────┤
│                  │
│   嗨，我在这儿    │  ← 短问候（可换人设称呼）
│                  │
│  《书名》· 继续   │  ← 有进行中：一行即可点进共读
│                  │  ← 无进行中：此行隐藏，或极弱「去 Chatbox」
│                  │
│      ∧ 上滑      │  ← 进小屋枢纽（默认落在书架 Tab）
│                  │
└──────────────────┘
```

**顶区动效（定案：2 为主、1 打底）**

| 层 | 做什么 |
|----|--------|
| **1 打底 · 窗光** | 顶区一抹天光/窗色随时刻缓变（晨偏冷、午偏暖、夜偏暗）；慢、无声 |
| **2 为主 · 呼吸** | 同一光带轻轻起伏 = 连接状态：网关正常→稳呼吸；异常→停或变暗（装饰与健康是一件事，不另开绿点） |

可叠加（弱）：有「书名·继续」时顶区多一丝灯火/书意微动；空闲几乎只靠 1+2。

**动效开关约定（稳，防打扰阅读）**

| 状态 | 顶区动效 |
|------|----------|
| 待机 | 开（轻、慢、无声） |
| 小屋 Tab 页 | 更弱或关 |
| 共读中 | **关** |
| 系统「减少动态效果」 | 全程静 |

**刻意不放在待机上的（功能仍在，入口挪走）**

| 原待机元素 | 改去哪 |
|------------|--------|
| 今日微信时长 | **记录** Tab 统计区弱入口 |
| 五图标快捷 | **废止**；能力只在底栏四 Tab |
| 大块「共读进行中」卡 | 收成一行「书名 · 继续」；详情在共读中 / 书架顶卡 |
| 顶区假听筒/信号装饰 | 废止；改氛围光带 |

**交互**

- 「继续」→ 共读中  
- 上滑 → **小屋枢纽**（默认 **书架** Tab）  
- 无进行中：不硬塞第二按钮；上滑进小屋即可，Chatbox 开场仍是主路径  
- 点顶区氛围（可选）：异常时弱入口进设定「连接与健康」

## 屏 2 · 小屋枢纽（底栏 Tab + 复古卡片）

**目的**：小屋日常枢纽。**有底部 Tab**；各 Tab 内容是**复古圆角卡片**（列表 / 统计网格），不是家具场景热区。  
仍包在小手机壳里。共读中不显示底栏。

### 壳层与壁纸（皮 · DEMO 已试）

```
┌────────────────────────┐
│ 标题              ⇣   │  ← 奶油外圈；⇣ 弱回待机
├────────────────────────┤
│ ┌─和纸──────────────┐ │
│ │ ✿  爪印壁纸画框  ✿ │ │  ← 壁纸**不铺满全屏**；缩进成画框
│ │    〔卡片内容〕     │ │  ← 上下和纸条 + 四角贴纸点缀
│ │ ✿              ✿ │ │
│ └─和纸──────────────┘ │
│  ( 书架 笔记 记录 设定 ) │  ← 毛玻璃胶囊底栏，浮在奶油外圈上
└────────────────────────┘
```

| 层 | 做法 |
|----|------|
| **外圈** | 奶油 / 纸色；标题与底栏坐在这里 |
| **画框** | 爪印薄荷巧克力壁纸（`wall.jpg` 一类）只铺在中间圆角区；左右上下留边 |
| **边框素材** | 顶/底和纸条；角上贴纸（花、豆、点心等）— 装饰，不可点 |
| **卡片** | 半透明奶油底、大圆角、轻阴影，压在壁纸上保证可读 |
| **底栏** | 胶囊 + 毛玻璃；四项等分：图标 + 短文案 |

（家具场景 / 咖啡屋柜台风 = **延后主题备选**，见文末；默认导航不靠点家具。）

### 底栏四 Tab

| Tab | 主区放什么 |
|-----|------------|
| **书架** | 顶卡「继续共读」；书卡列表（封面缩略 + 书名作者 + **刷次 pill** + 进度/时间元数据）；可导入 |
| **笔记** | 按书 → 按章卡片；划线/想法/跟批摘要；搜索后做 |
| **记录** | 顶部分段（总/日/周/月/年）；统计四宫格；近 7 日柱；场次摘要卡列表 |
| **设定** | 见屏 4；整页一张设定卡 |

子页示意（书架）：

```
┌────────────────────────┐
│ 书架              ⇣   │
├────────────────────────┤
│ ┌──────────────────┐ │
│ │ ☕ 《书》·继续共读 │ │  ← 顶卡进本场
│ └──────────────────┘ │
│ ┌──────────────────┐ │
│ │▣ 书名 · 作者      │ │
│ │  [一刷][二刷][+下一刷] │
│ │  元数据 · 进度 %   │ │
│ └──────────────────┘ │
│ …                    │
│ (书架·笔记·记录·设定) │
└────────────────────────┘
```

记录 Tab 示意（统计风）：

```
┌────────────────────────┐
│ 记录                   │
│ (总|日|周|月|年)        │
│ ┌────┐ ┌────┐         │
│ │时长│ │册数│  …      │  ← 2×2 统计卡
│ └────┘ └────┘         │
│ ┌ 近7日 柱图 … ┐      │
│ └──────────────┘      │
│ ┌ 摘要卡 · 本场 ┐     │
│ └──────────────┘      │
│ (书架·笔记·记录·设定) │
└────────────────────────┘
```

**导入书（定案）** — 与前相同：

- **格式不限**：epub / txt / pdf / 其它常见格式均可入库。  
- **沉浸共读与强跟批**：优先 epub、txt；pdf 可看、跟批/锚点降级。  
- **一套壳**：不另做「导入版 / 微信版」两套导航。  
- 有本地正文时，开场可选共读方式（见屏 3）；也可仍选划线共读。

大屏半幅：卡片与画框随窗格宽度缩放。手机无分屏：微信整屏划线 ↔ 切 PWA 共读（正式动线）。

**可点 DEMO**：见同目录 [`UI-DEMO.html`](UI-DEMO.html)（素材试用，非正式定稿）。

## 屏 3 · 共读中

**目的**：跟批与短聊；气质贴近 Chatbox 对话流。**无小屋底栏**；不穿插四 Tab。

**共读方式（按书选，非两套 App）**

| 方式 | 何时可用 | 共读中长什么样 |
|------|----------|----------------|
| **划线共读** | 始终可选（仅微信 / 有本地正文都可） | 现在这套：跟批时间线为主；正文在微信（或你在别处读）；手机可整屏微信 ↔ 切 PWA |
| **沉浸共读** | 仅**有本地正文**时可选 | **同一套**顶栏 / 消息 / `+`；中间（或左侧）多一块**正文窗**，同屏划线+跟批 |

- 默认：有本地正文可默认沉浸，开场/本场仍可改成划线共读。  
- 无本地正文：只有划线共读。  
- 切换只改共读中布局与正文来源，**不换枢纽、不换线程模型（仍按刷次一条对话）**。

**线程定案（三层）**

```
书
 └─ 刷次（一刷 / 二刷…）← 一条 Chatbox 式对话
      └─ 本场（今晚这场…）← 默认「只看本场」
```

- 不是「全书永远一条线」，也不是「每一场一条 Chatbox」。  
- **对话粒度 = 刷次**：一刷一条对话，二刷另开一条；书架标注并点进对应刷次。  
- **开下一刷**：以用户确认「开始下一刷」为准；进度骤降等只作弱提示，不自动开刷。  
- **本场**：刷次内可分多次读；进共读默认滤镜 **「只看本场」**（可关，上翻本刷更早场次；场次分隔条）。  
- **超长**：落在最新；上滑分页加载；不靠左右翻卡。

**划线与刷次（微信不分刷次）**

- 微信侧仍是书级划线池；刷次只活在小屋。  
- 归因：二刷开始后新同步 / 本场活跃中的新划线跟批进当前刷；可手动挪；底库按书存一份。  
- 联动：同句/本章与上一刷对比（「一刷时怎么说」）；不假装微信能标刷次。

```
┌──────────────────────────────┐
│ 《书名…》·一刷 62%   19:05 ···│  ← ··· 可含：共读方式（有正文时：沉浸⇄划线）
├──────────────────────────────┤
│ （默认只看本场）               │
│ 〔沉浸时：此处可分栏正文窗〕    │  ← 划线共读则无此块
│ (头) 你划了：「……」           │
│ (头) 已深度思考               │
│      跟批正文…                │
│      12 tokens · …           │
│      [换一条][复制][…]       │
│ …                              │
├──────────────────────────────┤
│ ┌ 输入框……………      [发送] ┐ │
│ │ +  深思  对话  模型  上下文 │ │
│ └────────────────────────────┘ │
└──────────────────────────────┘
```

**顶栏**

| 元素 | 说明 |
|------|------|
| 书名·刷次·进度 | 主行；书名过长省略 |
| 时钟 | **设定里开关**「共读顶栏显示时间」；开才显 |
| `···` | 底部操作表：暂停跟批、结束本场、跟批方式、跟批额度；**有本地正文时：切换沉浸⇄划线共读** |

**中部（Chatbox 风）**

- 消息流：划线引用、跟批、你的短聊；可有头像 /「已深度思考」标记  
- **不做**左右翻卡；**不做**界面展示「命中世界书」（后台仍可静默注入）  
- 每条下方：**token/费用灰字常显**  
- 操作条：换一条（保留旧候选）、复制、更多（可含踩、看上一刷同句等）  
- 无夹在中间的「费用条 + 总结 + 笔记」工具带  

**底栏输入（仿 Chatbox）**

| 控件 | 作用 |
|------|------|
| `+` | 总结刚才；本章笔记（**滑出**，不整页跳）；其它次要场内动作 |
| 深度思考 | 开关本场是否先出思考 |
| 对话设置 | 语气等本场对话相关 |
| 模型 | 选跟批/小屋 LLM |
| 上下文总数 | 当前上下文体量（如 69K） |
| 输入 + 发送 | 短聊 |

**交互**

- `···` → 结束本场 → **摘要卡确认** → **回小屋枢纽·书架**（不回待机）  
- 历史摘要卡：记录 Tab（场次带刷次标签）  
- 换刷次：回书架 Tab 点「一刷/二刷…」，换整条对话  
- 预算上限不在共读页常驻 → **设定**；超限用时间线系统提示

## 屏 4 · 设定（Tab）

**目的**：改配置；主题后做但占位。从底栏 **设定** 进入；无「← 回客厅」，切 Tab 即可。

区块顺序建议：

1. 连接与健康（Key / LLM / 网关状态）  
2. 人设  
3. 剧情摘要（导入/分层）  
4. 世界书（**现行前端已关**；见落地进度）  
5. 跟批默认模式 / 语气 / **预算上限**（默认值 + 可改；共读中不常驻费用条）  
6. **共读顶栏显示时间**（开关）  
7. **外观 · 主题（占位；薄巧默认皮已挂，切换面板未做）**  
8. 房间钥匙 / 关门锁 / 备份

## 好看怎么保住

| 手段 | 做法 |
|------|------|
| 壳 | 圆角机身、细边、听筒；整屏待机完整展示 |
| 待机 | 极简：问候 + 继续一行 + 上滑进小屋；顶区窗光+呼吸 |
| 小屋枢纽 | **奶油外圈 + 壁纸画框 + 和纸/角贴**；内容用复古卡片；**毛玻璃底栏四 Tab** |
| 共读中 | 壳减细边、铺满窗格；结束回书架 Tab；Chatbox 风时间线；壁纸可淡点缀，正文区保持干净 |
| 动效 | 待机：窗光+呼吸；小屋 Tab 更弱；共读中关；尊重系统减少动态 |
| 主题（后做） | 色板 / 壳 + **壁纸&边框素材包**；导航结构仍为底栏四 Tab |
