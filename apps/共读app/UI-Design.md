## 0. 设计定案（一句话）

**薄荷巧克力皮**：奶油外圈 + 爪印壁纸画框 + 和纸/贴纸点缀 + 复古圆角卡片 + 毛玻璃底栏；壳层已扩成 **锁屏 / 桌面 / 小屋**；共读中是 Chatbox 风时间线（头像、深度思考正文、候选翻页、token 灰字、底栏工具条），**无小屋四 Tab**。

## 1. 信息架构与导航（现行）

```
锁屏（无底栏；壁纸 + 时日 + 状态栏装饰）
  └─ 上滑解锁 → 桌面
桌面（主题壁纸 + 组件行 + 双头像/胶囊 + App 栅格横滑 + Dock）
  ├─ 「共读」→ 小屋枢纽（默认书架 Tab）
  ├─ 「设置」→ 手机设置页
  ├─ 日历 / 聊天 / 共看 / 共听 → 各真路径（模块在 apps/*）
  ├─ 其它图标 → stub（生活/花宠/共漫/2.5D 小屋等）
  └─ 下滑 → 回锁屏
小屋枢纽（底栏：书架 | 笔记 | 记录 | 设定；← 回桌面）
  └─ 点书 / 刷次 → 共读中
共读中（无小屋底栏）
  └─ 结束 → 摘要卡 → 回书架 Tab（不回锁屏/桌面）
```

壳：小手机圆角外框（整屏打开时完整展示）。大屏半幅共读中：内容铺满窗格，外框可减细边。

> **覆盖旧「三态」/「空 Dock」**：旧稿「待机问候 + 继续 → 小屋」与早期「仅共读小屋+设置+空 Dock」已被现行桌面取代；`UI-DEMO.html` 共读锁定稿仍有效，待机 DEMO 页不再当壳真源。小手机其它 App 勾选见母仓落地进度。

## 2. 设计 token（默认皮）

| Token | 值 | 用途 |
|-------|-----|------|
| `--paper` | `#f7f1e8` | 奶油外圈、待机底 |
| `--ink` | `#3a2e24` | 主文字 |
| `--muted` | `#8a7a6a` | 次要文字、元数据 |
| `--accent` | `#8b5a3c` | 强调、深思 on |
| `--ok` | `#6a8f6e` | 健康正常 |
| `--chocolate` | `#5c4a3a` | 发送钮、模型 pill |
| `--mint-line` | `#a8c9bc` | 划线引用左边线 |
| `--card` | `rgba(255,252,247,.94)` | 复古卡片 |
| 圆角卡 | `18px` | 枢纽卡片 |
| 圆角气泡 | `12px` | 跟批气泡 |
| 底栏胶囊 | `999px` | Tab / 分段 |

字体：系统中文无衬线栈（PingFang / YaHei / Segoe）。字重靠层级，不另引入花体标题（除非主题包后加）。

动效：待机窗光+呼吸；小屋弱；**共读中关**；尊重「减少动态效果」。

1. 小屋画框内壁纸用 `background-repeat`；锁屏/桌面壁纸用 **cover** 全屏。枢纽内容区**嵌在画框内**，不铺满奶油外圈。

3. 贴纸装饰默认 `pointer-events: none`；可点控件必须有明确热区与文案。  
4. 字不直接压在深色格子上：卡片 / 气泡 / 半透明纸色托底。

## 4. 屏 · 锁屏

```
┌──────────────────┐
│     信号 Wi‑Fi 电 │  ← 装饰状态栏（点按不查网关）
│                  │
│      21:40       │
│    星期二         │
│  2026年9月29日    │
│                  │
│   ∧ 上滑解锁     │
└──────────────────┘
```

- **壁纸**：`lock-wall.jpg` 全屏 cover；**不加**半透明暖罩（曾试方案 A，糊图已撤）。  
- **不放**：问候文案、书名继续、灵动条、网关/健康入口、底栏。  
- 上滑或点底提示 → **桌面**（不是直接进小屋）。

## 4b. 屏 · 桌面

```
┌──────────────────┐
│  (主题壁纸)       │
│  [🐻共读小屋] [⚙设置] │
│                  │
│  ┌── Dock 空框 ─┐ │
│  └──────────────┘ │
│       ───         │  ← Home 指示器
└──────────────────┘
```

- 下滑回锁屏；小屋内 `←` 回桌面。  
- Dock **仅框**，内无 App（后续再放）。浅色细边，**无** backdrop-blur。  
- 桌面 App 名：「设置」；小屋底栏 Tab 名仍为「设定」。

## 5. 屏 · 小屋枢纽（底栏 + 画框卡片）

### 5.1 层结构（必须）

```
奶油外圈
 ├─ 顶栏：← 回桌面 | （空） | 当前 Tab 标题
 ├─ 画框（圆角）
 │    ├─ 顶和纸
 │    ├─ 角饰：左上蝴蝶结 + 右下杯子蛋糕（装饰）
 │    ├─ 爪印壁纸 + 滚动卡片内容
 │    └─ 底和纸
 └─ 毛玻璃胶囊底栏 ×4
```

- 壁纸**不铺满**外圈；左右上下奶油留白。  
- 底栏：书架 / 笔记 / 记录 / 设定；选中态加深不挑高亮紫。  
- **无**书架置顶「继续共读」卡（自行点书）。

### 5.2 书架 Tab

- 书卡：左缩略、右标题作者、**刷次 pill**（一刷/二刷/+下一刷）、底元数据  
- pill 色：柔和紫/薄荷/peach，巧克力字

### 5.3 笔记 Tab

- 顶：搜索 + 右侧「导出」（选 Markdown / Word）  
- 复古卡片列表：书摘要 → 章卡（划线数 · 跟批数）

### 5.4 记录 Tab

- 顶：时段胶囊（全部|今日|本周|本月）+ 右侧「导出」  
- 2×2 统计卡 + 共读时长柱图 + 场次列表

### 5.5 设定拆分

| 入口 | 内容 |
|------|------|
| 桌面「设置」 | 连接与健康、人设、访问密码、外观·主题占位、顶栏时钟 |
| 小屋「设定」 | 剧情摘要（旧全局）、跟批默认（方式+额度）、备份导出/恢复 |

设定行右侧次要文字与整行 **垂直居中**。

## 6. 屏 · 共读中（锁定稿）★

> **用户明确满意的界面。实现必须与 DEMO 共读页一致。**  
> 对照：`UI-DEMO.html` → `#view-coread`；视觉参考用户提供的共读截图。

### 6.1 整体骨架

```
┌─ 顶栏：书名·刷次·进度 | (时钟?) | ··· ─┐
├─ 和纸条（washi2）────────────────────┤
├─ 滤镜条：豆贴 +「默认只看本场 · 薄荷巧克力皮」┤
├─ 消息区（淡壁纸；角上淡贴纸）──────────┤
│  [场次和纸分隔]                         │
│  (头) 划线引用…                         │
│  (头) 💡已深度思考    ‹ 1/2 ›           │
│       ┌气泡┐                            │
│       └token 灰字                       │
│       [↻][✎][⧉][⋮] 操作条              │
├─ composer 卡（顶 washi）───────────────┤
│  输入 placeholder「在这里输入…」         │
│  ＋  深度思考  对话设置  ↑上下文  [Deep Seek▾]  (发送) │
└────────────────────────────────────────┘
```

**禁止**：小屋四 Tab；左右翻卡；跟批旁展示「命中世界书」列表；中间费用大条+总结+笔记工具带。

### 6.2 顶栏

| 元素 | 规格 |
|------|------|
| 标题 | `《书名》·一刷 · 62%`；单行省略；字重 **400**；约 14px |
| 时钟 | 桌面「设置」开关；关则占位空 |
| `···` | 开启底部操作表（含本刷摘要；**无**关门锁入口） |

顶栏底：奶油半透明，**无硬分割线**；其下紧贴和纸条（`.cr-washi` / `washi2`）。

### 6.3 滤镜条

- 背景：薄荷绿半透明（暂停跟批时**仍绿**，只加深字色）  
- 左：小贴纸（如 `sticker-bean`）  
- 文案：本场状态只读（时间线范围在 `···`）  
- **无**随消息滚动的角贴

### 6.4 消息区

- 背景：淡爪印壁纸 + 高透明纸色罩（正文可读）  
- **无**右上花 / 左下点心随滚装饰（已去）  
- 场次分隔：居中短和纸带（`washi3`；跟批流顶 `session-tape` 已去）

**用户划线行**

- 左：圆形头像（你）+ 薄荷描边光晕  
- 右：左边线薄荷的引用「划线：「…」」  
- 下：灰字 meta（如 words / 章信息）

**助手跟批行**

- 左：圆形头像（小屋 / 熊）  
- 头行：深度思考开且有正文 → `<details>` **默认展开**思考面板（可收起）；右侧 **`‹ n / m ›` 候选翻页**  
- 气泡：白底 `rgba(255,255,255,.94)`、圆角 12、浅棕边、轻阴影  
- 下：`412 tokens · 380 cached` 类灰字**常显**  
- 操作条：白底圆角横条，四键 **↻ 换一条 | ✎ 编辑 | ⧉ 复制 | ⋮ 更多**（分隔竖线）  
  - 来源：满意 DEMO；线框写「换一条/复制/更多」，**编辑**以 DEMO 锁定稿为准并入 PRD C7  
- `⋮` 更多可含：踩、OOC 重生、看上一刷同句（P2）、本场少剧情（C12b）

短聊：同气泡样式，可无 think / 无操作条。

系统提示（预算刹停等）：弱样式气泡或居中灰字，不伪装成跟批。

### 6.5 Composer（底栏输入 · 仿 Chatbox）

独立圆角卡，浮于底安全区之上：

| 元素 | 规格 |
|------|------|
| 容器 | 奶油底、圆角 16、薄荷浅边；**顶部一条 washi** |
| 输入 | 无框，placeholder「在这里输入…」 |
| `+` | 左侧；旁可贴 treat 小图；点开抽屉：总结刚才、本章笔记 |
| 深思 | 开关；on 用 accent 色 |
| 对话 | 对话设置 |
| ↑nK字 | 上下文体量（设计示例写 ↑12K；**现行已按字数实时标 `↑nK字`，可点拆分**） |
| 模型 | 深巧克力 pill，白字，`Deep… ▾` |
| 发送 | 圆钮 32px，巧克力底，↑ |

工具行单行可横滑；发送 `margin-left: auto`。

### 6.6 覆盖层

- `···` → 底 sheet：暂停跟批、跟批方式、跟批额度、结束本场、取消；（有正文）沉浸⇄划线  
- `+` → 侧/底抽屉，不整页跳转  
- 结束 → 摘要卡确认 → 回书架

### 6.7 沉浸共读（有正文时）

- **同一套**顶栏 / 消息 / composer（跟批层打开时像素对照仍适用）  
- **手机沉浸默认**：正文近全屏；跟批时间线+composer 收起  
- **头像浮钮**（右下可拖）：本场陪伴头像（否则小屋默认）；点开/再点关 → 自下而上大半屏跟批层  
- **新跟批**：浮钮轻闪 + `--badge-dot` 小圆点角标（无数字、不自动弹层）；换主题时改 CSS 变量即可  
- 窄窗格也可上下分栏（划线共读仍常驻时间线）  
- 不得为此换皮肤底图或换导航

### 6.8 共读验收（像素级对照）

实现完成时，与 DEMO 共读页并排比对，须同时满足：

- [ ] 顶栏文案结构 = 书名·刷次·进度 + ···  
- [ ] 顶下和纸 + 滤镜条文案结构一致  
- [ ] 划线引用左边线为薄荷，非蓝紫链接风  
- [ ] 深思行 + 候选 `‹ n/m ›` 在气泡上方同一头行  
- [ ] token 灰字在气泡下、操作条上  
- [ ] 操作条四键横条样式一致  
- [ ] composer 顶和纸 + 工具序：+ / 深思 / 对话 / 上下文 / 模型 / 发送  
- [ ] 无底部四 Tab  
- [ ] 头像为素材圆形猫/熊风，非默认灰头像
