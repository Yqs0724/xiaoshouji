## 入口与皮

- 桌面「共听」→ `#view-colisten`（`pwa/view.html` 注入壳 index；CSS `pwa/colisten.css`）
- 逻辑：`/assets-colisten/colisten.js`；皮素材母仓 `/assets/colisten/`
- 设置行「Apple Music」：`connection: shelved` / 文案「搁置」（非真授权流）；点进手机设置**子页**（`#appleMusicPanel`，`ColistenApp.expand` → `openSettingsSub`）
- 统一备份：`listen.json` 进包；导出时剔 Apple Music 令牌（`scrubListenObj`）

## API（挂共读网关 `/api/v1/listen/*`）

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `session` | 本场 + 当前曲 + `tracks` 歌单 + 吐槽 + 提议 + `liked` |
| GET | `presence` | 桌面胶囊 / 资料「正在做什么」（需 `engaged`） |
| POST | `engage` | 进播控打点，避免空场误显 |
| POST | `favorite` | 切换当前曲（或 `trackId`）收藏 |
| GET | `history` | 已结束场次摘要 + 收藏列表 |
| POST | `control` | `play` / `pause` / `next` / `prev` / `select`(+`trackId`) |
| POST | `spit` | SSE：你侧 + 家机流式回句 |
| POST | `end` | 结束本场并开新场（写 history 摘要） |
| POST | `proposal` | `{ demo:true }` 或 `{ decision: confirm\|ignore }` |
| GET/PATCH | `auth` | 搁置说明；health：`apple_music: "shelved"` |
