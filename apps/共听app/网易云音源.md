# 网易云音源（Cove 阶段 A）

聊天点歌优先走网易云：**搜歌 → 本机兼容 API 取流 → 网关代理整曲 → 音乐卡可播**。

## 1. 起兼容 API（本机）

推荐 [NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)（或兼容实现），默认端口 `3000`：

```powershell
npx --yes NeteaseCloudMusicApi@4.32.0
```

浏览器打开 `http://127.0.0.1:3000` 有响应即可。

## 2. 绑定账号（推荐扫码，免 F12）

1. 兼容 API 与网关都开着（API 默认 `http://127.0.0.1:3000`，没起则扫码会失败）  
2. **电脑浏览器**打开小屋 → 设置 → **共听音源**  
3. 点 **扫码登录** → 用手机网易云 App 扫 → 确认  
4. 提示「已登录并保存」即可（Cookie 只存本机，不回显）

扫码链路：网关对 `/login/qr/*` **不带旧 Cookie**，且 `check` 带 `noCookie=true`（否则确认时常 502 / 卡在等待）。

会员曲搜不到/只听试听：多半是 Cookie 被截断或混入了 Set-Cookie 属性。**重新扫一次码**即可（现已清洗并放宽长度上限）。

F12 没反应时不必抠 Cookie。若仍要手动：只粘 `MUSIC_U=…; __csrf=…` 这种键值，不要整段 Response Headers。

也可用环境变量：`NETEASE_API_BASE_URL`、`NETEASE_COOKIE`。

## 3. 用法

- 日常聊天让家机点歌；出卡后**点音乐卡**播放（再点暂停）。
- 共听页：＋ → **点歌**，或输入 `点歌 晴天`；播放中可**拖进度条**。
- 失败时会回落 Apple 试听（若优先=自动）。

## 4. 阶段 A 接口（验收）

| 能力 | 路径 |
|------|------|
| 搜歌 | `GET /api/v1/music/search?provider=netease&q=` |
| 详情 | `GET /api/v1/music/song/netease/:id` |
| 代理流（Range） | `GET /api/v1/music/stream/netease/:id` |

无音源/API 挂了会返回明确 `error` + `message`（不笼统写 VIP）。

## 5. 阶段 B 共同状态

| 能力 | 路径 |
|------|------|
| 读会话 | `GET /api/v1/music/session` |
| 写事件 | `POST /api/v1/music/session/event`（play/pause/resume/finish/close…） |
| 阶段总结 | `POST /api/v1/music/session/summary` |

库文件：`共听app/data/music_library.json`（锁+原子写；close/finish 滚阶段总结；2h 活跃租约）。

**2h 租约**：距上次 play/resume 不超过 2 小时才算「正在共听」；超时只当历史。

## 6. 阶段 C 歌单 / 队列

| 能力 | 路径 / 用法 |
|------|-------------|
| 导入 | `POST /api/v1/music/playlists/import`；共听 ＋→导歌单，或 `导歌单 <链接>` |
| 列表/详情/删 | `GET/DELETE …/library/playlists[/:id]` |
| 队列 | `GET/POST /api/v1/music/queue`（from_playlist / enqueue / clear） |
| 加入我的歌单 | `POST /api/v1/music/netease/playlists/add-song`（需扫码） |
| 音质/音量 | 设定「共听音源」 |

## 7. 阶段 D 跨页单播

- 壳脚本：`/assets-colisten/cove-player.js`（`window.CovePlayer`）
- 聊天音乐卡与共听播控共用**同一个** `<audio>`，切视图不断播、不叠声
- 多标签：`BroadcastChannel` + `localStorage` takeover（他页开播本页被动暂停，不记成用户 pause）

## 8. 阶段 E 今日私选

| 能力 | 路径 |
|------|------|
| 读/生成 | `GET /api/v1/music/daily-discovery?limit=16`（`refresh=true` 换一批） |
| 反馈 | `POST /api/v1/music/daily-discovery/feedback`（like / heard / more_like_this / less_like_this / dislike） |

- 程序搜验真歌 → **F：LLM 从白名单排序+写理由**（失败则确定性兜底）；同日缓存 `data/music_daily_discovery.json`
- 共听首页标签「今日私选」懒加载；可整单入队、点播、轻反馈
- `strategy.llm_ranked` / `llm_model` / `llm_error` 可看是否走过模型

## 「只能听一部分」对照 Cove

| 情况 | 教程依据 | 怎么辨认 |
|------|----------|----------|
| Apple 降级 | V4f / 30s preview | 卡上写「试听30s」 |
| 未登录 / Cookie 弱 | §4.2 登录增强、§6.1 Cookie 优先 | 只有试听片段或 `MUSIC_TRIAL_ONLY` |
| 会员/版权 | §21 错误表 | 搜得到但无整曲流 |
| 代理被掐断 | §7 须完整流式 + Range | 网关已去掉短超时掐流 |

## 边界

- 非官方兼容接口，可能变更；Cookie 勿提交 Git、勿发给模型。
- 不是每首歌都有流；会员曲要有效登录态（设定里扫码）。
- 音频经本机网关代理，勿对公网裸奔。
