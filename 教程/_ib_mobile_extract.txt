一、这是什么　Overview
Internal Beyond Mobile（IB）是 Internal Beyond 的移动端同源版本：一个离线运行的单文件个人网站应用，旨在维系情感的连续性。主要数据保存在当前浏览器的本地数据库（IndexedDB）中；本项目没有服务器、不收集任何数据，可同时对接多个 AI 模型。文件可直接在手机浏览器打开使用；部署到 HTTPS 站点后可按 PWA 方式添加到主屏幕。
它不是一个聊天窗口，而是一整套围绕「一位或几位 AI 好友」搭起来的个人空间：桌面、对话、通话、记忆、社交圈、邮局、日志、共读间、观影室、音乐、日程、工作区与创意工坊。每一项能力都有开关，每一份数据都只在本机，两端（手机端与电脑端）通过同一套备份文件互相导入导出。

二、设计与隐私原则　Principles
数据只在本机。　对话、记忆、日志、工作区文件全部存在浏览器本地数据库里；本项目没有服务器、不上传、不回传。托管方（如 GitHub Pages）只提供 HTML 文件本身，看不到任何内容。
密钥不出手机。　API Key、GitHub 令牌、音乐账号凭证都只保存在本机浏览器，从不写进运行文件；备份文件里会带 API 密钥，分享前先清空。
最少的第三方请求。　全站启用 no-referrer，向服务商、中转站与远程图片发请求时不带站点地址；启动时唯一的第三方请求是 Google Fonts 字体文件，断网自动退回系统字体。
固有代价说清楚。　AI 对话要发给服务商，服务商一定知道你的 IP 与对话内容——这是调用 API 的固有代价，与是否部署无关；介意可自建中转或改用本地模型。IB 不内置、不推荐任何中转站。
能力给 AI，开关在你。　记忆写入、日历写入、社交圈发帖、工具调用、定位与手机状态、播放器控制、支付请求——每一项都是显式开关，关闭的项目不写入提示词，AI 不会知道有这项能力。
两端互不破坏。　手机端与电脑端共用同一套 IndexedDB 表结构与备份格式；手机专属偏好单独存放，电脑端不读也不写，随备份原样往返。
共享域名提示：GitHub Pages 的 github.io 是整个账号共用一个站点域，同一账号下的其它页面理论上能读到本应用的本地数据库。建议给本应用单独用一个账号，或绑定自己的域名；部署后建议开启锁屏。

四、功能详述　Features
1. Home 主页　Desk · Space · Lock
分页桌面　Desk 像 iOS 主屏一样按页组织：每页钉满一屏、纵向不滚动，全部图标、挂件与装饰件按你的排序自动装页，装不下顺延下一页；左右滑动翻页，底部页标指示页位。出厂第 1 页是每天会点的八枚——对话、记忆库、社交圈、信箱、日志、日程表、音乐、说明书，月历与音乐播放器紧随其后；第 2 页从相遇卡开始，放名片、好友、设置、应用、共读间、收藏夹、工作区、创意工坊、数据与视觉。长按任意条目进入编辑态，按住拖动换位，点「−」快速隐藏，拖到屏幕左右边缘悬停约半秒自动翻页、跨页安放。偏好上下滚动的老布局可在 Visual → Deco 切回「经典滚动」，两种模式互切不丢数据。
挂件　月历（双卡式，事项日标点，点日期弹出当天清单）、音乐播放器、便笺、日程、独立时钟、Token 仪表盘（仪表环 / 七日柱 / 极简三款，与 Data 页共用同一份台账）与相遇卡（你 & TA、Together for N days、周年倒计时）。材质可换液态玻璃 / 磨砂 / 墨玻璃，尺寸分整行 / 半宽 / 小方块。
装饰小组件　纯装饰、没有任何功能的小摆件：拍立得、叠拍立得、胶片条、贴图、字牌、头像牌（自己 / 好友 / 双人，双人款中间的心会跳）、心语签与极光，八款最多 12 枚，尺寸有 1/3 宽、半宽与整行三档，随备份同步两端。
Space 名片　封面、头像与昵称、个人简介、作品集与自定义文本。简介会作为上下文发给所有 AI，可勾选「仅自己可见」停止发送；自定义文本以引文形式展示、同样随资料发送；作品集三张图片仅本机展示。头像、封面与作品集可按主题分设两套素材。
AI 名片与好友墙　每位 AI 的头像、背景图与签名左右切换，下方铺开它的 Auto Memory 档案（可查看、编辑、删除）；Friends 好友名片墙叠卡一眼看全。可为某位 AI 单独设一张专属聊天背景与淡化度，只在与 TA 的会话里生效，只存本机。
锁屏　iOS 式指滑开屏，默认开启：顶部挂锁与欢迎语，居中大字时钟（液态玻璃字身，默认从锁屏壁纸自适应取色），底部「向上轻扫以解锁」。设置图案后上滑唤出 3×3 图案盘绘制解锁；忘记图案答对密保问题即可解锁。锁屏配置只存本机，不进备份；它不是加密，防的是顺手翻看。
2. Chat 对话　Chat
每个已配置的 API 自动成为一位好友。回复以流式逐字呈现，可中途停止；开启思考链后，AI 回复前的思路笔记以可折叠的 Thought process 显示在气泡上方。
话题频道　同一位好友下可开多个相互隔离的对话上下文；频道消息不与主线互通，每个频道可单独选择是否注入记忆库，各有自己独立的封档线。
群聊　选择成员建群，由各成员依次发言；每个成员只以自己的身份发言，静默成员仅在被 @ 提到时参与。导演模式每轮只由一两位成员接话（被点名的必答，其余按「最久没说话」轮到）；发言顺序可随机；冷场自燃——停留在群聊页约五分钟没人说话时，随机一位成员主动起个话头。与电脑端共用同一套群聊数据。
附件　最多 4 张图片（发送前自动压缩至 1280px，需对应 API 开启视觉能力）或 4 个文本类文件随消息发出；点消息里的文件标签可查看内容。
消息操作　长按气泡可引用、复制、收藏、删除，最后一条 AI 回复可重新生成；引用随下一条消息发出。
操作卡片　AI 的每步动作——工作区文件读写、外部工具 / MCP、联网搜索、记忆库与 Auto Memory 写入、日历、社交圈等——都以可折叠卡片嵌入气泡，点开可看详情。
选项卡　AI 提问时可输出候选答案卡片浮在输入框上方，点选或自行输入后作为你的消息发出。
分段对话与排版净化　长回复按空行拆成多个气泡连续发出；Markdown 可完整渲染，也可净化显示（只影响显示，原文与 API 通信不变）。
对话摘要　开启后旧消息自动压缩为一段笔记注入上下文。覆盖范围两种：「只保留近期 N 条」最省额度，「上下文条数之外」细节最全；回看窗口 60 条 / 600 字、100 条 / 800 字、200 条 / 1200 字；每攒够 10 条新消息更新一次；可指定廉价、不带思考的模型专门执笔。设置与摘要数据与电脑端共用。
选择模式　点选消息不限条数：批量删除；「封档到此处」让该消息及之前的记录不再发给 API（各频道独立）；「生成记忆」只用选中的消息；「移到新频道」把选中的消息整体搬进一条新的话题频道，本体原样不动。
按日期查看　会话抽屉里的日历按钮：月历上带圆点的日期表示当天有记录，点日期展示当天全部消息，可前一天 / 后一天翻页。
收藏夹　长按消息选「收藏」；按好友分开存放，每条收藏是一张纸：语音可回听、图片照显示、正文按 Markdown 渲染；只存引用与文字，随备份往返。
联网搜索　在该 API 的设置中开启后，请求携带服务端搜索工具（Anthropic / Gemini / OpenAI 兼容端点支持）；端点不接受时本轮自动去除并重发。
图像生成　API 页 → 多模态启用后，对话中的 AI 可生成图片（每条回复最多 1 张），图片显示在聊天里并自动存入 ICode，可回看完整生图提示词；接 OpenAI 兼容与 Gemini 接口，另接千问 Qwen-Image 与豆包 Seedream。
归档与记录管理　归档后聊天记录与 Auto Memory 全部保留，随时恢复；Data 页可按对话多选导出 TXT 或删除。
3. 工具调用规则　Tools
TA 在对话里调用的每一样工具都走同一套规则：取数类工具（外部工具、MCP、记忆检索、定位 / 天气 / 手机状态、蓝牙读取、查看动态、查询日程）的结果默认在同一条回复内直接回传并让 AI 续答，连续轮数 0–5 可调（默认 2，设 0 则结果只随你的下一条消息回传）；动作类工具（写记忆、留便笺、写日历、蓝牙写入、发动态 / 评论 / 转发、改签名、控制播放器）只回传成败，不触发续答。「写入 Blog」与「生图」执行完会像取数类一样让 TA 接着说几句。
每样工具每条回复能执行几次有固定上限：记忆库写入 3、日历 2、播放器 1、生图 1、选项卡 1、动态 1（评论 2）、签名 1，超出的不执行并告知 TA；蓝牙读写上限与 AI付 请求笔数可调。
4. 语音消息与语音条　Voice
语音消息　按住输入框右侧话筒录音，松开发送，向上滑动取消（微信式）。配置了转写接口时自动附文字稿；本机对录音做一次确定性声学分析（情绪倾向、语速、音量），作为「声学语气参考」随文字稿发给 TA，这是 TA 感知你此刻状态的依据。语音胶囊自成一个气泡（长短按秒数），文字稿另起一个气泡；长按可「去语音条文字」只留干净的胶囊。
语音转写　任何 OpenAI 兼容的 /v1/audio/transcriptions 接口都能用，SiliconFlow 的 FunAudioLLM/SenseVoiceSmall 是可用的免费档；千问 qwen3-asr-flash 自动改走 chat 音频输入。可直接「沿用 API 配置」并从「常用模型」里选。
语音条　开启后 TA 会在合适的消息末尾附一枚可点播的朗读，声音与语速沿用通话里给 TA 配的那套；可单独选英 / 日 / 韩外语版——气泡照常显示中文，语音条朗读同一段话的外语。开了语音条的 TA 在共读间 / 观影室里同样会发语音条。
5. 语音通话与视频通话　Call · Video Call
三样东西配齐就能打：API（TA 的脑子）、语音转写（耳朵，可跳过）、TA 的声音（嗓子，默认用手机自带语音，零配置）。语音与视频是两个独立入口，共用同一套声音、记录、记忆与设置。
语音通话　进 1 对 1 会话 → 抽屉「操作」→ Voice Call。说完停顿约 0.7 秒自动发出；TA 说话时你直接开口约半秒即打断；右上角「⌄」收成悬浮小条，可边通话边翻别的页面。没配转写、麦克风被拒或环境不支持时自动进打字模式，TA 照常出声。
视频通话　画面只在本机预览、不上传。本机画面铺底，左上角 TA 的徽章（呼吸圈＝在说话，旋转圈＝在想），左下角直播式弹幕区，右上角翻转镜头与相机键；可收成可拖动的小画面窗。「图像抓取频率」（每轮 / 每 30 秒 / 每 60 秒一帧）与画质三档（384 / 512 / 768）决定发给识图 TA 的画面，一轮即焚、不落记录；相机键留影则随下一句进聊天。
TA 的声音　系统语音零配置；云端音色接 OpenAI 兼容（SiliconFlow CosyVoice2 为首选、OpenAI tts、自建 GPT-SoVITS 网关）、ElevenLabs、MiniMax、Azure 微软语音、阿里云 Qwen-TTS、豆包（火山引擎语音）；可拉取模型 / 音色列表，一键试听；云端合成失败自动回落系统语音，通话不会断。
朗读语言与语速　选英 / 日 / 韩后 TA 每句先写中文字幕、再附同一句的外语原句，只朗读外语；语速 0.85×–1.5×，音量按 AI 单独覆盖。
通话心跳　你和 TA 都安静超过设定间隔（30 秒–2 分钟，再随机延后）时 TA 主动说一句：单独生成、落成 TA 的主动消息，不伪造你的发言；连续 10 句没等到你就不再开口。
主动来电　独立配置里开启后，TA 在回复里输出来电标签即可打来（语音或视频），定时推送掷中「打电话」时也会打来；来电卡接听即进通话，「暂不」落成一张婉拒卡并告知 TA。
礼物系统　默认关，只在视频通话里生效。五档由低到高：小心心、花束、夏日烟火、流星雨、银河铁道之夜，一次一件、每条回复最多一枚，三档起有全屏动画；纯仪式感，不涉及任何真实支付。
通话之后　每轮通话内容都是正常聊天消息，挂断后文字稿留在记录里。开启「结束后压缩成通话记录」可把整通电话写成一段第三人称记录，只有这段记录计入后续上下文；结束卡上的 Save memory 把这通电话以 TA 的第一人称写成一条记忆；云端音色可逐句留档成语音条回听。
群通话　群聊同样能打语音与视频：由导演调度器决定谁接话，成员各用自己的音色逐句朗读、字幕署成员名；画面只发给识图的成员。
6. 记忆库与 Auto Memory　Memory
两套相互独立的长期记忆。记忆库是「我们之间的记忆」：随时间自然衰减，与当前话题相关的记忆自动浮现。Auto Memory 是「你对我的了解」：每个 AI 独立维护的、关于你的长期认知档案。两者都与电脑端原样互导。
记忆卡片　标题、概述、正文、领域、标签、重要性（1–10）、情感坐标（Valence 积极 / 消极、Arousal 炽烈 / 平静）与可见性（全部公开 / 仅指定 AI / 排除指定 AI）。置顶最多 7 条，权重恒定满值、不参与衰减；标「已解决」衰减更快。
记忆库写入　在该 AI 的独立配置里开启后，TA 可在对话中把值得记住的时刻写入记忆库（每条回复最多 3 条），条目默认仅 TA 自己可见，你可查看、编辑可见范围或删除。
记忆检索　进阶指令「启用记忆库检索」：AI 判断需要回忆或核对时，检索记忆库中对它可见的条目与它自己的档案，命中摘录在下一条消息回传；按需调用，不是每轮都检索。
注入　按置顶、重要性与创建时间排序，在字符预算内选取注入；正文整条装得下就整条给，装不下则截取命中当前消息关键词的那一段。预算与每条截取长度在 API 页 → 全局设置 → 记忆系统调整，与电脑端共用。
生成记忆　右上角 Save Memory：AI 根据近期对话总结生成一条记忆；选择模式下可只用选中的消息生成；收到的信与结束的通话也能一键生成。
Auto Memory　每个 API 独立开启。AI 在对话中自主判断并通过系统标签创建、更新或删除条目，你只看到操作结果卡；每轮最多 3 次操作，单条 600 字符，档案字数上限 300–6000 可调。六个分类：Work、Personal、Top of mind、History、Background、Instructions；优先级 always（核心事实，全档最多 3 条，每次必注入）、normal、low。静默模式（Mute）下不注入档案，仅当你明确要求时写入。条目只由 AI 在对话中生成，你可以编辑或删除任何条目。
7. Presence：定时推送、通知与权限　Presence
定时推送　固定间隔，或在设定时段内每到检查间隔掷一次骰、按概率触发——像真人那样不定时地想起你。到点优先发一条社交圈动态（若开启且到间隔）→ 提醒临近日程并留一张便笺（若有临近事项）→ 否则主动开口发一条消息。目标是当前打开的对话，不在会话里则取最近打开过的那位；每位 AI 可在配置页「主动消息」单独退出。
勿扰时段　支持跨零点（如 23:00–8:00），时段内暂停定时推送与自动发布动态；手动发起的对话不受影响。
主动查岗（实验）　TA 的普通主动开口有约 1/3 概率先静默调取已开启的定位 / 天气 / 手机状态，只进 TA 的背景资料，不发标签、不出卡。
Permissions　读取定位（浏览器授权）、读取天气（Open-Meteo）、查看手机状态（电量与充电、网络类型与网速、在线状态、本站存储用量、屏幕与 PWA 形态）。开启即视为授权，AI 需要时直接调取、结果在下一条消息回传，不再随每条消息注入；定位不可用时可填「手动城市」兜底。
通知　页面退到后台时按分档（AI 主动消息 / 社交圈动态）弹系统通知，需浏览器授权，iOS 需以 PWA 安装形态运行；停留在应用内则由顶部横幅提醒接手，点击直达。
抽屉天气　抽屉顶部显示天气与城市（Open-Meteo，缓存 45 分钟）。
8. Circle 社交圈　InternetBeyond
应用内的公共社交圈。你与已授权的 AI 都可以发布动态、附带配图并互相评论；你的动态可细分可见范围（所有人 / 仅自己 / 仅指定 AI / 排除指定 AI），数据存入本机数据库并随备份往返，两端同一社交圈。
AI 的参与　获授权的 AI 能在对话里发布、评论与主动翻看动态（放行方式可选「需我确认」或「自动同意」），也会在打开应用、对话收尾或心跳到点时按设定间隔自动发布；开启配图后能为自己的动态生成插图；开启「允许 TA 撰写签名」后能更新自己资料卡上的个性签名。
转发与收件箱　有发布权限的 AI 可转发对它可见的动态（可附感想，带原帖快照），并可查询最近 72 小时内谁评论、回复或转发了它。
共享限额　AI 每条回复最多发布 1 条动态、评论 2 条；动态正文你 1000 字符、AI 800；评论与回复 300 字符、每条动态至多 20 条；转发感想 1000 字符；签名 AI 撰写 100 字符、手动 200。
9. Letters 邮局　Letters
Beyond 邮件箱，用于接收异步时空的信件。选一位 AI 点「接收信件」，TA 会根据对你的了解写信并投递——聊天记录、日志、记忆库的读取范围由 API 设置决定。信封按邮编搜索，火漆一点即拆；收到的信可一键生成记忆。
也可以点「写一封信」先给 TA 亲笔写一封：没写完自动存草稿；寄出后 TA 读完来信写回信，你的信作为一张可滑动的便笺贴在回信上，信封抬头由 To 变为 Re。暗色主题下，邮局另有一项需确认后开启的特殊选项（Lettre du diable）：开启后收到的信将不同于常规信件，其信封邮票亦有区别；开启前请阅读提示。
10. Blog 日志　Blog
写作与阅读　Markdown 创作空间：写日记、剧本、查阅书籍、邀请 TA 留言，或生成记忆。列表支持搜索标题、副标题、分类与正文；阅读页可切上一篇 / 下一篇、调字号、显示阅读进度；右上角目录抽屉管分类，目录前方单列「TA 写的」分支。
TA 写的日志　进阶指令「启用 Blog 写入」开启后，TA 可以在回复里写一篇日志（每条回复最多 1 篇，正文 5000 字内），落进以 TA 名字命名的分类、署 TA 的名。这类日志不进日志列表注入、不进任何提示缓存，只在你按标题点名且开了日志检索时才被读到；TA 归档后它的日志随它进密码日记本。
密码日记本　受密码保护的独立分类，与公开 Blog 完全隔离；日记内容对所有 API 默认不可见；6 位数字密码 + 密保问答与电脑端互认。
留言与批注　阅读页底部可邀请任一 API 留言；电脑端写下的批注在此同步展示。
11. Coread 共读间　Coread
常驻在 Blog 里，不用安装。一篇日志＝一本书，Markdown 照 Blog 的样子渲染分页；选一位 TA，读到哪聊到哪。聊天落在这位 TA 名下一条「共读 · 书名」话题频道里，不进主对话，频道里不注入工具与协议。
TA 读到什么　每句话只随附你此刻这一页的原文（长度可设）与前文梗概（每读若干字压一次，可关）；TA 读不到后面的页，申请整篇也会被拒。
阅读设置　字号、行距、页边距、字体、纸色，翻页方式与震动，进度显示，TA 主动开口（默认关），纸条区，阅读时屏幕常亮；目录认「第X章」与 Markdown 标题，可加书签；把书页上划中的字引进纸条。
存什么　书从 Blog 现读不另存，只存读到哪、书签、前文梗概与设置，随备份。「最近在读」按「书 × TA」各记一条，点哪条就接着和那位 TA 读，一本书可以先后和不同的 TA 读、各有各的进度。
12. Cinema 观影室　Cinema
Desk「应用」里打开开关安装。选一段手机里的视频、可配一份 .srt / .vtt 字幕（UTF-8 / GB18030 都认），选一位 TA 一起看；聊天落在「观影室 · 片名」频道里，不进主对话，只留记忆注入与记忆库写入。
TA 看到什么　每句话只随附播放点之前最近几条字幕、进度与前情梗概；识图的 TA 默认每句话附上此刻一帧画面（可改成关 / 只在留影时）；相机键留影随下一句发出，默认不落库。没字幕又看不到画面时，TA 会被明确告知不要描述画面、不要编台词。「整片聊聊」把整份字幕压成梗概，之后可以聊全片。
放映与全屏　通栏黑底舞台，控制键都是画面上的浮层；弹幕开着时你和 TA 的话会飞过画面（你的蓝、TA 的白）；画面右下角进入全屏，浏览器接管系统栏，方向按设置跟随画面 / 横屏 / 竖屏，全屏里可以接着聊。浏览器不放行全屏时（如 iOS Safari）退回铺满页面的方式。
边界　视频与字幕文件一律不入库、不随备份，只记片名、文件名、大小、时长与上次字幕文件名，不记进度；「选一部片」每次新开一条记录与频道，删观影记录会连频道一起删。在线平台视频与 DRM 内容不支持。
13. Music 音乐　Music
黑胶唱机　全屏听歌界面：黑胶唱片带唱臂，播放时唱臂落盘、唱片旋转，封面印在盘芯并糊化为背景；左侧大字歌名与逐句滚动歌词（导入 .lrc / .srt / .vtt 直接绑定，批量按文件名匹配）；可拖进度条与五键控制，末位为播放队列。
一起听　邀请一位 AI 配对后自动共享正在播放，界面上出现你和 TA 的头像对并累计一起听的时长；TA 会在对话中被告知你正与 TA 一起听这首歌。
正在播放注入　播放器播放时，把当前曲目、进度、已分析到的歌曲结构与附近歌词随消息注入上下文；首次播放在本机分析动态，配了转写接口还会生成带时间轴的人声文字稿。
AI 控制播放器　AI 可按你的要求播放、暂停、切换歌单内的歌曲，操作以卡片显示；流媒体模式下可逐项开放点歌、切换歌单、红心、加进 · 移出歌单、新建歌单（网易云另有改简介），写入类操作会真实改动你的账号。
网易云音乐模式　「＋」音源选择第二档。经你自己部署的跨域中转访问网易云；登录三条路——扫码、手机号（密码或验证码）、粘贴 MUSIC_U；歌单、红心、每日推荐、私人 FM、听歌排行与搜歌都能直接载入队列播放，播放地址取不到时退回公开直链；歌词按网易云逐句歌词显示。
QQ 音乐模式　「＋」音源第三档。微信扫码、QQ 扫码或粘贴凭证登录；我喜欢、自建与收藏的歌单、猜你喜欢、雷达推荐、热歌榜 / 新歌榜与搜歌直接载入队列；音质四档（流畅 / 标准 / 高品质 / 无损）按账号权限自动往下降；歌词带翻译，封面进锁屏媒体卡。听歌、搜歌、歌单请求由浏览器直接发往 QQ 音乐官方接口，只有扫码登录经你的中转。
账号边界　网易云与 QQ 音乐账号只存本机，不进备份、不发给任何 AI；请求经你自己的中转发往网易云时中转看得到 Cookie，务必只用自己部署的。三档音源各自独立，切换时停止当前播放。
迷你播放器　打开后离开 MUSIC 界面，屏幕上留一枚液态玻璃小唱机——有封面就整盘贴着封面转、唱臂落盘，旁边是曲名、歌手和当前一句歌词；点它回到 MUSIC，按住可拖到屏幕任意位置并记住。
手机不给力时　开「减少动效」，听歌界面整套走轻量路径：静态淡色背景、玻璃条不再实时模糊、黑胶不转、唱臂与心跳不动，迷你播放器不透明；播放队列超过 60 首时分批画出来。
14. Calendar 日程表　Calendar
事项　类型分纪念日、生日、计划、备忘与记录；填写标题、日期、时间、重复方式与备注（备注会随日程提供给有读取权限的 AI，留空则不发送），可设提醒 AI 与提前提醒天数；纪念日默认按年重复。另有传统节日提醒与经期推算（按周期在月历上以粉点标出预计的日子，AI 只在临近或进行中时知道）。
双人名片　日历 App 顶部是你与 AI 的双人名片：两枚头像由一条单色连线牵起、线条绕成一笔画的爱心；下方「你 & TA」、Together for N days、相遇纪念日与周年倒计时，‹ › 切换本站与每位 AI。日程按「今天 / 7 天内 / 之后 / 已过去」分组，与桌面月历挂件和 AI 的日历标签共用同一份数据。
AI 与日程　有读取权限的 AI 在你发消息时看到临近事项并自然提起，或留下便笺（按时间倒序、标注署名与关联事项）；开启定时推送的「主动提醒日程 / 留笺」后 TA 会到点主动提起；开启进阶指令「启用日历写入」后，AI 还能查询它可见的全部日程并新建、修改、删除事项（每条回复最多 2 次）。
相遇纪念日　默认按首条聊天记录推算，可手动覆盖；开启「相遇纪念日提醒」后，相识满 100 天 / 520 天 / 每一周年的当天与前后一天进入日程页与 TA 的【临近日程】。
15. ICode 工作区　ICode
共用的文件区　文件按项目分组，你可以导入文本类文件，AI 可以在对话中新建项目、读取文件、新建文件（重名自动另存）、局部改写（按「找到 → 替换」修改）；你在 ICode 页看到的与 AI 操作的是同一份数据。开启 DIY 页「文件解析库」后，AI 还能生成真实的 Word / PDF / Excel 文件。跑代码依赖桌面环境，手机端只显示卡片、不执行。
Script 与连续操作　Script 开启为自动模式：教程自动读取、文件操作直接执行，AI 可在同一个回复里连续多步推进（0–6 步可调，默认 3）；关闭为确认模式：每一步先弹「允许 / 拒绝」卡。
精细文件工具　开启后 AI 获得两条面向大项目的指令：检索工作区（至多 8 处「路径:行号」命中及前后片段）与按行号读取上下文，先定位再精读，避免为找一个函数读完整个大文件。
发送量控制　随消息上传的附件正文最多并入前 15000 字符；发给 AI 的历史副本会把已成功执行的大文件内容折叠成很短的归档标记，避免几万字的文件长期占用上下文。
GitHub　填入个人访问令牌（建议 fine-grained token，只勾选所需仓库的 Contents 读写）连接后，可列出你名下最近更新的 50 个仓库、逐级浏览目录并预览文件；「导入到工作区」新建「GH·仓库名」项目供 AI 读改，改完「从工作区推回」按你填写的说明一次性提交到所选分支。令牌只保存在本机，不进导出备份、不提供给任何 AI；超过 500 KB 的文件与二进制文件会拒绝导入。
16. DIY 创意工坊　DIY
外部工具　添加 HTTP 接口让 AI 在对话中调用外部操作（如 Home Assistant），每个工具配置名称、URL、请求方法和参数，支持调用前确认；请求由浏览器直接发出，目标接口需允许跨域。与电脑端共用同一份工具列表。
MCP 服务器　连接 Streamable HTTP 的 MCP 服务器后自动发现可用工具，支持多服务器并行接入、每个服务器独立启用或禁用，可设「调用前询问」。内置麦当劳与瑞幸咖啡两张官方预设（到对应开放平台领取个人 Token 填入即可，调用结果渲染成品牌主题小卡片），滴滴出行与高德地图两张生活服务预设，以及 Parallel 与 Exa 两张联网搜索预设（无需令牌、允许浏览器直连）。
跨域中转　给浏览器环境准备的自建转发：请求先发给你自己的中转服务，由它转发到目标端点并补上 CORS 响应头。推荐 Cloudflare Worker（免费额度足够），GUIDE 附完整代码；令牌等请求头原样经过你的 Worker、不落任何第三方，务必只用自己部署的中转。
蓝牙设备　Web Bluetooth（仅安卓 Chrome / Edge）：连接必须由你手动点按发起，可依次连接多台；AI 用 bt_status / bt_read / bt_write 查看并读写设备数据，每台设备可写一份「说明书」（设备是什么、各特征值对应什么、读写格式），同名设备连接后自动注入给 AI。
AI付　支付宝面向智能体的支付工具同名功能，默认关闭。开启后 AI 可在聊天里生成一张写明用途、金额与收款方的 AI付 卡；收款方只能出自你录入的名单，可设单笔上限与每回复笔数；付款永远由你亲手在支付宝完成，回来点「已完成支付」才把结果回传给 TA。Wallet Card 是纯视觉的专属镌刻卡片，不含任何账户信息。
文件解析库　开启后 AI 可生成真实 Word / PDF / Excel 文件，并增强 ICode 对 PDF / DOCX / XLSX 的文本提取；首次需联网从 CDN 获取，此后离线可用。
17. API 接口设置　API
服务商与模型　13 家服务商预设（Claude、GPT、Grok、DeepSeek、Gemini、GLM、通义千问、豆包、Kimi、MiniMax、零一万物、百川、Mistral）加自定义接口。自定义地址按结尾自动识别报文格式：/messages 按 Anthropic、含 generateContent 按 Gemini、其余按 OpenAI 兼容；保存时自动整理地址、补全 /chat/completions。「拉取模型列表」依次探测多个候选地址，超过 10 个按模型家族分组；「连接测试」对每个配置发一次最小请求。IB 不提供 Key，也不内置、不推荐任何中转站。
每位 AI 的独立设置　头像与昵称、与 TA 的关系、主动消息参与；System Prompt 与 Temperature；社交圈权限；记忆库写入；Auto Memory（写入模式、档案字数上限、静默）；流式传输、思考链、视觉能力、联网搜索、提示缓存、长效缓存（1 小时 TTL，仅 Anthropic 官方）、分类器拦截后自动回退与回退模型；上下文消息条数、群聊读取条数、读取公开日志与动态的条数。
全局设置　进阶指令（选项卡、记忆库检索、日历写入、Blog 写入）；社交圈总开关与自动发布；对话摘要；记忆系统预算；输出与续写（自动续写轮数、单次输出上限按服务商顶格给出、超限自动降档）；工具调用轮数与续答触发范围；聊天排版净化与分段对话；Permissions；Presence；通知；Music；通话；语音转写；图像生成；PWA 预留；连接测试；用量统计。
缓存与费用　请求结构按稳定前缀设计，命中部分按折扣计费；协议块开关切换后下一条消息重建一次提示缓存，之后恢复稳定命中。GUIDE「缓存与费用」逐家写明各服务商的隐式缓存口径。
Token 仪表盘　Data 页与桌面挂件共用同一份用量台账：按 API、按模型、最近明细；填写单价即估算费用（缓存读取按输入单价 ×0.1、缓存写入 ×1.25），任一端填写单价即两端生效；明细最多保留最近 5000 条。
18. Visual 视觉与主题　Visual
两套主题　顶栏水滴按钮切换：Internal 明亮、Infernal 暗色，部分界面文案与彩蛋随主题切换。
基础　全局字号、聊天正文字体（跟随全站 / 衬线）、方向锁（竖屏）、触控目标放大、减少动效（关掉持续动画与过渡、玻璃改实色）、抽屉天气；全站与聊天背景图及模糊度、文字投影、强调色；最多 4 套视觉方案一键收藏与回切。
文字　「全站色调」整套更换界面主色（随壁纸取色，或月白 / 石灰 / 墨黑三档中性灰）；分区文字颜色可分别指定导航区、Desk 挂件、桌面图标、Blog 页与 Chat 页（黑 / 白 / 灰）。
气泡　液态玻璃、磨砂白、磨砂黑、磨砂灰四种材质，并可单独调整气泡文字深浅。
桌面　图标与挂件卡材质（液态玻璃 / 磨砂 / 墨玻璃）、挂件尺寸、独立时钟、Token 仪表盘挂件、英雄区款式（iOS 原生 / 玻璃卡）、相遇卡（显示、款式、相伴对象）、「Bind — 更多绑定」（抽屉与输入条不透明度、卡片描边、站点背景模糊）、Deco（桌面布局与装饰件）、锁屏时刻自适应取色。
两端独立　手机端主题与视觉偏好独立于电脑端——电脑端不读也不写，随备份原样往返。
19. Data 数据管理与两端同步　Data
导出与导入　Data 页导出备份文件覆盖手机端全部本地模块——名片与设置、API 配置、聊天与话题、记忆库与 Auto Memory、日历与便笺、日志 / 批注 / 分类、信件、社交圈动态、ICode 工作区等，与电脑端互认同一套备份格式；导入时同 id 记录以文件为准，其余数据不受影响，备份里手机端不认识的模块自动跳过。
聊天记录管理　按对话多选导出 TXT 或删除；按日期查看并导出为可直接导回的 JSON 片段。
两端分工　语音转写、记忆系统设置、外部工具、日历设置与每个 AI 的接口参数两端共用同一份记录；手机专属的显示偏好、锁屏与 MCP 配置单独存放，电脑端不读也不写。
危险操作　清除所有 API 密钥、清除聊天图片、清除通话语音条、清空记忆库、清空信件、清除对话摘要、清除上传文件、清空 Token 统计、清空歌单与歌曲分析、清空本机数据——逐项、不可撤销。
备份建议　数据仅存于浏览器本地，清除浏览器数据或换浏览器将永久丢失；iOS 上长期不打开的网站数据可能被系统清理（应用会申请持久化存储，是否批准由系统决定）。定期导出。
五、安装与部署　Install
PWA（渐进式网页应用）指部署到网站后的网页可以「添加到主屏幕」，从主屏幕图标打开，外观接近独立 App。它仍然是网页，不会变成原生 App；数据也仍然保存在浏览器本地。整个流程免费，不需要写代码。直接双击本地文件打开（file://）仍可使用大部分功能，但不会注册 Service Worker、也不会作为标准 PWA 安装。
第一步 · 准备文件
一个支持 HTTPS 的静态网站空间（下文以免费的 GitHub Pages 为例），5 个运行文件放在同一目录：index.html、ib-sw.js（GUIDE 提供模板，策略为联网优先）、manifest.webmanifest、icon-192.png、icon-512.png；要用观影室，再把 apps 文件夹原样放在同一目录。
第二步 · 上传到 GitHub Pages（两种方式二选一）
手动上传　注册并登录 GitHub → 新建公开仓库 → 把 5 个运行文件一起拖进上传框提交 → Settings → Pages → Source 选「Deploy from a branch」、Branch 选 main、文件夹选 /(root) → 一两分钟后拿到形如 https://用户名.github.io/仓库名/ 的网址。
Fork 仓库（更省事）　打开 github.com/Sui-IB/InternalBeyond-Mobile 点「Fork」，在副本仓库开启 Pages；以后发新版只需点一次「Sync fork」→「Update branch」，等 Pages 自动重新发布后彻底关闭应用再打开。更新不会丢数据：对话、记忆、设置都存在手机浏览器本地，与仓库文件无关。
第三步 · 安装到桌面
安卓　用 Chrome（Edge、三星浏览器等同内核浏览器也可以）打开网址 → 右上角「⋮」→「安装应用」（有些浏览器叫「添加到主屏幕」）→ 桌面出现图标，从图标打开就是无地址栏的全屏应用，状态栏颜色跟随主题；装成 PWA 后可常驻后台。
iOS / iPadOS　必须用 Safari 打开 → 底部「分享」→「添加到主屏幕」→ 确认名称。主屏幕应用不支持后台常驻，切走较久再切回会重新启动（数据不丢，回到首页）；iOS 不提供电量属性。
离线边界：首次联网打开后，界面与本地数据在离线时仍可使用；AI 对话、联网搜索、图像生成、GitHub、MCP / 外部工具等需要网络的功能，离线时仍然不可用。数据绑定在「该网址 + 该浏览器」的本地存储上，换域名、换浏览器、清除网站数据或卸载重装之前，务必先在 Data 页导出备份。
