# 共读小屋

本机网关 + PWA。网关是唯一数据源。

**实现勾选真源**：[`落地进度.md`](./落地进度.md)。新窗口开工：[`开工提示词.md`](./开工提示词.md)。

## 密钥（DeepSeek 等）

复制或直接编辑仓库根目录 [`.env`](./.env)：

```env
DEEPSEEK_API_KEY=sk-你的密钥
LLM_BASE=https://api.deepseek.com
LLM_MODEL=deepseek-flash
# PERSONA=叫我阿州，语气轻松
# PERSONA_CARD=完整角色卡（可选）
```

填好后**重启** `npm start`。环境变量优先于桌面「设置」连接面板；`.env` 已在 `.gitignore`。

## 启动网关

```powershell
npm start
```

默认：`http://127.0.0.1:8787`（可用环境变量 `PORT` 改）。

浏览器打开锁屏页：<http://127.0.0.1:8787/>（上滑→桌面→共读小屋）

健康检查：

```powershell
curl.exe http://127.0.0.1:8787/api/v1/health
```

应看到 `"llm":"configured"`（密钥填对并重启后）。

### Chatbox · MCP（电脑）

共读号 / 剧情号挂**同一**工具集。**仅桌面 Chatbox**：**新建对话前**先选 **工作模式**（开聊后不能改），再打开「共读小屋」开关。

```text
node d:\cursor-projects\小手机\共读室\gateway\mcp-server.mjs
```

cwd（若有）：`d:\cursor-projects\小手机\共读室`

| 工具 | 作用 |
|------|------|
| `health_check` | 本地设定是否配齐 |
| `list_bookshelf` | 读本机书架缓存 |
| `sync_bookshelf` | 同步微信全量书架（进度补最近+在读） |
| `get_progress` | 当前/指定书进度 |
| `get_last_session` / `get_session_summary` | 最近一场 / 按 id 摘要（同库） |
| `start_coread` / `end_coread` | 开场·恢复 / 结束本场（可选 `write_lore`，默认 false） |
| `set_mode` / `set_budget` | 改本场跟批方式 / 额度（须已开场） |
| `set_door_lock` | 开关门锁 |
| `list_notes` / `search_notes` | 笔记索引 / 关键词搜索（本地） |
| `ask_idle_read` | 本场空闲自读日志 |
| `open_book` | 选书 + PWA / 微信网页链（不开场、无 App 深链） |
| `get_recent_coread_context` | 接戏用近文上下文（截断） |

自检：`npm run check:mcp`

**手机 Chatbox**：官方工作模式目前仅桌面；移动端**不能**稳定调 MCP 开场。手机共读请用 **本机 Web**（阅读器旁开 `http://…:8787`）。远程 HTTP MCP（`npm run mcp:http`）代码保留——**暂不作为手机 Chatbox 用法宣传**。Base URL Tool 循环搁置。
