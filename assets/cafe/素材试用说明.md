# 素材试用说明

你丢在 `素材/` 里的包，主体是 **咖啡屋 / 甜品贴纸 + 和纸胶带 + 壁纸图案**，几乎没有「沙发、书架、落地灯」这类客厅家具。

**现行 PWA 皮**（非 DEMO 一一对应）：见 [`落地进度.md`](../落地进度.md)「外观」、[`主题预留.md`](./主题预留.md)、[`bq/README.md`](./bq/README.md)。待机已去掉四角贴纸；弹窗外框现行用 `wall.jpg` + `bq/sheet-top|bot.png`。

## 以后更好用素材

1. **客厅默认皮**：另买或自制「家具透明底 PNG」（沙发/书架/灯/桌），文件名对齐槽位。  
2. **这批咖啡屋素材**：正好留给线框里的 **咖啡屋主题场景皮**（槽位同构换皮）。  
3. **丁当胶带**：顶栏/分隔装饰，不要当整页底图。  
4. **壁纸 JPG**：只做 `background-repeat` 淡纹，上面务必盖一层纸色半透明，否则字会糊。

蝴蝶结 60 个：共读里可作偶尔装饰，别进客厅主槽。
